### The real application (`apps/repl`, `index.jsx` entry)

| backend | plain | minified | gzip (of minified) | gzip (of plain) | vs baseline (min) |
|---|---|---|---|---|---|
| `baseline` | 49.2 kB | 24.2 kB | 8.5 kB | 13.7 kB | +0.0 kB (0.0%) |

| `c-alien-backend` | 64.3 kB | 31.5 kB | 10.8 kB | 16.9 kB | +7.4 kB (30.5%) |

**Reading the size numbers:**

* The interop-only directions (A/E/F) cost ~1.8 kB gzip in the *core-only* graph even if the app
  never interops, because `_shared/alien-compat.js` imports alien statically. Making that import
  lazy (or moving it to its own subpath) would keep a non-interop app at baseline size — a concrete,
  cheap improvement if A/E/F are chosen.
* B costs **+0.8 kB gzip** over the baseline for the whole computed/batching/tracking axis, because
  it has no dependency to pull in. It is the cheapest direction by a wide margin.
* C costs **+2.8 kB gzip** in the core graph and **+2.3 kB gzip** in the real app: alien is
  ~1.8 kB gzip of that, and it cannot be tree-shaken away because the storage layer is alien.
* E/F cost the same as C in the core graph (~3.7–3.8 kB gzip) while providing less (no eager mode,
  no dispose of computeds) — their value is opt-in adoption, not size.

## 3. Interop with alien-signals: possibilities, ergonomics, failure modes

Executed probe matrix. `native` = the direction’s own signals are alien nodes (no bridge at all);
`bridged` = works through `toAlien`/`toSignal` or automatic dependency normalisation;
`needs-bridge` = works only if the caller bridges, otherwise silently stale; `static`/`stale` = it
does not work and does **not** throw.

| probe | `baseline` | `a-compat` | `b-native` | `c-alien` | `e-alien-native` | `f-bridge-hybrid` |
|---|---|---|---|---|---|---|
| **P1** alien computed reads a jsx6 signal, no bridge | ⚠️ needs bridge | ⚠️ needs bridge | ⚠️ needs bridge | ✅ native | ⚠️ needs bridge | ⚠️ needs bridge |
| **P2** alien computed reads a bridged jsx6 signal | — unsupported | 🔗 bridged | — unsupported | ✅ native | 🔗 bridged | 🔗 bridged |
| **P3** alien effect reads a jsx6 signal | ⚠️ needs bridge | 🔗 bridged | ⚠️ needs bridge | ✅ native | 🔗 bridged | 🔗 bridged |
| **P4** jsx6 $F depends on an alien signal | ❌ static | 🔗 bridged | ❌ static | ✅ native | 🔗 bridged | 🔗 bridged |
| **P5** alien computed in a JSX position (observeNow) | ❌ static | 🔗 bridged | ❌ static | ✅ native | 🔗 bridged | 🔗 bridged |
| **P6** two-way: jsx6 write → alien computed → jsx6 observer | — unsupported | 🔗 bridged | — unsupported | ✅ native | 🔗 bridged | 🔗 bridged |
| **P7** isObservable() recognises alien nodes | ❌ static | 🔗 bridged | ❌ static | ✅ native | 🔗 bridged | 🔗 bridged |

### What the interop probes mean in practice

**Which directions need a bridge, and which do not**

* **C needs none.** Its `prepareSignal` stores the value in an `alien.signal`, so a bare jsx6 read
  inside an alien `computed`/`effect` registers a dependency natively (P1), and `toAlien($sig)` is a
  zero-allocation lookup of the backing node rather than a listener bridge (P9). This is C’s one
  structural advantage over every other direction.
* **A, E and F need a bridge** for every value that crosses (P1/P3/P6 all report `needs-bridge`),
  because their signals are the original closure-backed ones.
* **The baseline and B have no bridge at all** — not even a helper. A user with alien in the app can
  still hand an alien node to jsx6 code, and that is where the two silent failure modes appear.

**The two silent failure modes (no exception, wrong result)**

1. **Alien node handed to a jsx6 derived signal** (P4/T10): the untouched `$F`/`$S` decide
   “derived vs static” with their own `isObservable`, which does not know alien nodes, so the alien
   node is treated as a *static value*. `$F(v => v * 2, alienSignal)` returns the alien node itself
   — the derived signal holds a function, and the UI renders the function. Compat fixes this by
   normalising the dependency list (`toSignal` mirrors) before delegating; C fixes it by extending
   its own `isObservable` to accept alien nodes.
2. **Alien node used where JSX expects a signal** (P5/T11): `insertAttr` and `nodeFromObservable`
   treat any function value as a signal and call `observeNow` on it. With no alien-aware branch the
   updater receives the function itself and runs once — `{$computed}` renders source instead of a
   number. This is the single most user-visible interop bug, and it is why A/E/F/C all override
   `observe`/`observeNow`/`subscribe`/`isObservable` rather than only adding `toAlien`.

**Bridge ergonomics, honestly**

* **Direction of travel matters.** Bridging jsx6 → alien is a *listener* (one alien signal + one
  `subscribeSymbol` registration per source). Bridging alien → jsx6 is an *effect* (one root alien
  effect per node, which is what keeps the mirror hot). Both are cached, so calling `toAlien($a)`
  twice returns the same node (P9), and repeated `toSignal(node)` returns the same mirror.
* **Batching is not implied.** `batch()` in A/E/F defers only the alien effect queue, so a two-write
  update still notifies the *core* graph twice (T7). Anyone bridging expects `batch` to make the
  combined update atomic; it does not. This is the most surprising ergonomic gap in A/E/F.
* **Tracking is not transitive by accident.** An unbridged read inside an alien `computed` is just a
  function call: no dependency, no update, no warning (P1/T9). The rule a user must internalise is
  “alien sees only alien values; bridge at the boundary” — which is easy to state and easy to forget
  in a JSX prop.
* **Disposal is a third disposal mechanism.** A mirror or bridge owns an effect or a listener that
  must be released (`dispose(node)`), on top of the core’s `observeNow` unsubscribe and, in C, the
  computed’s push effect. Long-lived components make this the main risk of any interop direction, and
  it is why `dispose` was kept as a first-class export rather than an internal detail.
* **Ergonomic cost can be removed cheaply.** Two concrete improvements if an interop direction is
  chosen: (a) make the alien import lazy so non-interop apps do not pay its ~1.8 kB gzip; (b) accept
  a plain jsx6 signal in a JSX-visible position by auto-bridging inside `observeNow`, instead of
  requiring an explicit `toAlien()` call at every crossing.
