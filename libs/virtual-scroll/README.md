## Overview

A virtual scrolling utility with the following characteristics:
- HTML Element recycling
- Adjustable buffer

## Structure

- [virtual-scroll.js](src/virtual-scroll.js) is the core
- [scroll-controller.js](examples/scroll-controller.js) is an example that makes it work
- [docs/](docs) is a demo plus an example of usage
  
## How to run

Run:
```shell
npm run build
vite docs
```
